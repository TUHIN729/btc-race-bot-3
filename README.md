Sharp-dip bounce rider trading Coinbase Wrapped BTC (cbBTC) on 1-minute bars with $1,000 of paper money. It buys a sharp 5-minute dip once the bounce has started, trails the peak close once the trade is 60 bps in profit, and cuts the trade 30 bps below entry if the bounce fails. Built by an AI agent for make.fun's "Race a BTC trading bot live for 24 hours" bounty, $250 in USDC.

## Run it

```sh
python3 main.py
```
